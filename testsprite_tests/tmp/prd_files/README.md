# نظام قانون — النظام المتكامل لإدارة مكاتب المحاماة والاستشارات القانونية

نظام ERP عربي متكامل مبني وفق مواصفة `qanoon.pdf`، يغطي أربعة مسارات عمل مترابطة تنتهي جميعها إلى أرشيف واحد قابل للبحث.

| الطبقة | التقنية |
|---|---|
| الواجهة | HTML5 + CSS3 + JavaScript خالص (بدون أطر عمل، بدون خطوة بناء، يعمل بلا إنترنت) |
| الخادم | Java 21 + Spring Boot 3.3.4 (REST API) + Spring Security + Spring Data JPA |
| قاعدة البيانات | Microsoft SQL Server 2022 (مع H2 مدمجة لوضع التطوير) |
| التقارير | Apache POI لتصدير Excel + طباعة مباشرة من المتصفح |

---

## المسارات الأربعة

### ١ — الملف المالي
نقطة الدخول للتحصيل الودي قبل أي تصعيد قضائي.

- فتح الملف **يشترط إرفاق مستند المطالبة المالية**.
- تسجيل التواصل والإنذارات في خط زمني موثّق.
- خطة تقسيط تولّد أقساطها تلقائياً بتواريخ استحقاقها.
- **حالة الملف تُشتق آلياً من الدفعات المؤكدة فقط** — لا تُضبط يدوياً.
- **ارتجاع الشيك يعيد الأقساط التي سددها إلى الاستحقاق** ويخصم مبلغه من المحصّل.
- خمس وجهات لإنهاء الملف: سداد كامل، سداد بالتقسيط، رأي قانوني بالإغلاق، إعفاء بموافقة المستوى الأعلى، وتصعيد إلى قضية.
- **التصعيد ينقل كل المرفقات وكل سجل التواصل والإنذارات إلى القضية الجديدة دون إعادة إدخال.**

### ٢ — القضية والتنفيذ
من رفع الدعوى حتى الاستيفاء الجبري للحق.

- تسجيل الجلسات ومتابعتها أولاً بأول.
- توثيق الحكم: تاريخه، رقمه، ولصالح من صدر.
- **أجل الطعن يُحسب آلياً** = تاريخ الحكم + مدة الطعن القانونية (٣٠ يوماً افتراضياً وقابلة للضبط)، مع تنبيه تلقائي قبل انتهاء الأجل بسبعة أيام يبقى قائماً حتى اليوم الأخير.

**بوابة التحويل للتنفيذ — الشروط الستة**، تُفحص مرة على الواجهة ومرة ثانية على الخادم، وزر «تأكيد التحويل» لا يظهر إلا باستيفائها كلها:

| # | الشرط |
|---|---|
| ١ | حكم موثّق: تاريخه ورقمه مسجّلان |
| ٢ | الحكم ليس لصالح الخصم (لصالح الموكل أو جزئي) |
| ٣ | نهائية الحكم: موسوم صراحة كنهائي، **أو** انقضى أجل الطعن — واليوم الأخير نفسه لا يزال ضمن المهلة |
| ٤ | لا يوجد استئناف مُفعّل — أي استئناف معلّق يمنع التحويل ولو انقضى الأجل |
| ٥ | لم يسبق التحويل: لا ملف تنفيذ مرتبط بالقضية |
| ٦ | القضية غير مغلقة |

عند الرفض تعرض الشاشة **الموانع نصاً بالعربية**، مثال: «الحكم غير نهائي ولم ينقضِ أجل الطعن — ينتهي في 2026-08-15».

**التنفيذ**: خمسة أوامر يجوز إصدار أكثر من واحد منها في الوقت نفسه — حجز بنكي، منع سفر، ضبط وإحضار، حجز عقاري، حجز راتب. كل أمر يُسجَّل في الخط الزمني للملف بتاريخه وحالته.

**بوابة الاستيفاء**: الإغلاق ممنوع ما لم يكن المتبقي = صفر. وعند الاستيفاء يجري في معاملة واحدة: إلغاء كل الأوامر السارية دفعة واحدة، إصدار شهادة استيفاء مرقّمة، إغلاق الملف وأرشفته، وقيد في سجل النشاطات.

### ٣ — الاستشارات القانونية
مسار مستقل بمبدأ العينية، بسبع مراحل: استلام ← دراسة ← مراجعة ← اعتماد ← توقيع ← إرسال ← أرشفة (مع الإعادة بملاحظات).

**التوزيع الذكي** عند ترك المستشار فارغاً، بدرجة من ١٠٠:

| المعيار | الوزن | الحساب |
|---|---|---|
| مطابقة التخصص | ٥٠ | درجة كاملة إن طابق تخصص المستشار مجال الطلب |
| انخفاض الحمل | ٣٠ | كلما قلّت استشاراته النشطة (غير الموقّعة/المرسلة) ارتفعت درجته |
| الخبرة والأقدمية | ٢٠ | سنوات الخدمة منذ الالتحاق |

عند التعادل يُقدَّم الأقل حملاً. غياب المتخصص لا يوقف التوزيع. التوزيع اليدوي متاح دائماً ويتجاوز الترتيب كلياً. **وسبب كل إسناد موثّق نصاً.**

**المراجعة الثانية إلزامية**: لا يراجع كاتب الرأي رأيه، والمراجع يجب أن يملك صلاحية المراجعة.
**بعد التوقيع مقفل**: لا يُعدَّل الرأي ولو من المدير — وأي تصحيح يكون برأي جديد يشير إلى الأصل.

### ٤ — الأرشيف الشامل
كل ملف مغلق يُحفظ آلياً بمستنداته كاملة.

- مكتبة قانونية مرتبة هرمياً: **باب ← فصل ← مادة**.
- أحكام قضائية وآراء قانونية ونماذج ومراجع وتعليقات جاهزة لإعادة الاستخدام.
- بحث متقدم بفلاتر متعددة **يعمل بالكامل بالعربية دون أي اتصال بالإنترنت**.
- حفظ البحوث المفضّلة والرجوع لآخر خمسة بحوث.
- تصدير النتائج إلى Excel أو طباعتها مباشرة.

## الأمان والقواعد العامة

- **أربعة أدوار أساسية**: المدير (رؤية كاملة)، المحامي (ما أُسند إليه فقط)، المستشار القانوني (استشاراته فقط ولا يصل لشاشات الإعدادات)، كبير المستشارين (المراجعة والتوقيع النهائي) — **بالإضافة إلى أدوار مخصصة بصلاحيات دقيقة** مثل سكرتير أو موظف إدخال بيانات.
- تشفير كلمات المرور بـ BCrypt وسياسة قوة: ٨ أحرف، حرف كبير، حرف صغير، رقم، ورمز.
- **قفل الحساب تلقائياً بعد ٥ محاولات دخول فاشلة لمدة ١٥ دقيقة.**
- **سجل نشاطات كامل** لكل عملية إنشاء أو تعديل أو حذف، بالوقت وعنوان الجهاز — وكل محاولة دخول ناجحة أو فاشلة.
- **نسخ احتياطي تلقائي يومي** مع إمكانية نسخ فوري يدوي من الإعدادات.
- **الجلسة تنتهي تلقائياً بعد ٣٠ دقيقة من عدم النشاط.**

### القواعد الذهبية الثلاث
1. **المالي يقود الحالة** — الأقساط وحالة الملف تُشتق من الدفعات المؤكدة صعوداً ونزولاً. اليدوي محصور في إلغاء قسط وربط دفعة بقسط بعينه.
2. **ما وُقِّع لا يُكتب فوقه** — بعد التوقيع لا إعادة توقيع، ولا استبدال مستند، ولا رجوع لمسودة.
3. **كل وثيقة تتبع ملفها** — الإيصال وشهادة السداد وشهادة الاستيفاء والإنذار لا تُسلَّم إلا لمن يملك حق الاطلاع على الملف الأب.

## التشغيل

### المتطلبات
- Java 21 (JDK) — مثبّت في هذا الجهاز عبر `scoop`
- Apache Maven 3.9+
- Microsoft SQL Server 2022 Express (اختياري — انظر وضع التطوير أدناه)

### الطريقة الأسرع: وضع التطوير بقاعدة مدمجة
لا يحتاج SQL Server إطلاقاً. قاعدة H2 تُنشأ تلقائياً في مجلد `data/`.

```bash
mvn spring-boot:run
```

ثم افتح `http://localhost:8080`

### وضع SQL Server
القاعدة `QanoonERP` منشأة مسبقاً على `.\SQLEXPRESS` بترتيب مقارنة `Arabic_CI_AS`.

```bash
mvn spring-boot:run -Dspring-boot.run.profiles=mssql
```

الاتصال يستخدم **مصادقة ويندوز المدمجة** فلا يحتاج اسم مستخدم ولا كلمة مرور ولا تغيير أي إعداد أمني في الخادم. لتغيير الخادم أو القاعدة اضبط متغيّر البيئة `QANOON_DB_URL`.

> إن رغبت باستخدام حساب SQL بدل مصادقة ويندوز، فذلك يتطلب تفعيل الوضع المختلط (Mixed Mode) في الخادم وإنشاء حساب قاعدة بيانات — وهو تغيير في إعدادات الأمان تركناه لك. سكربت `sql/00_create_database.sql` يشرح الخطوات.

### بناء ملف قابل للتوزيع
```bash
mvn clean package
```
ثم:
```bash
java -jar target/qanoon-erp.jar
```

## بيانات الدخول التجريبية

كلمة المرور لجميع الحسابات: `Qanoon@123`

| المستخدم | الاسم | الدور |
|---|---|---|
| `admin` | مدير المكتب | المدير — رؤية كاملة |
| `lawyer1` | سالم المرزوقي | المحامي |
| `lawyer2` | هند الشامسي | المحامي |
| `consult1` | خالد النعيمي | المستشار القانوني (تجاري) |
| `consult2` | عائشة البلوشي | المستشار القانوني (عمالي) |
| `senior1` | د. يوسف الحمادي | كبير المستشارين |
| `secretary1` | منى الظاهري | سكرتير (دور مخصص) |

البيانات التجريبية تُزرع تلقائياً عند أول تشغيل فقط (عندما تكون القاعدة فارغة)، وتغطي كل الحالات: ملف بشيك مرتجع، ملف مُعفى، ملف مصعّد، قضية يمنعها استئناف معلّق، قضية اليوم فيها هو آخر يوم في أجل الطعن، قضية جاهزة للتحويل، ملف تنفيذ بثلاثة أوامر سارية، ملف تنفيذ مستوفى ومؤرشف، ورأي موقّع ومقفل مع رأي تصحيحي.

## بنية المشروع

```
src/main/java/com/qanoon/
├── domain/        الكيانات وقواعد البيانات الكائنية
├── repo/          مستودعات Spring Data
├── common/        الخدمات المشتركة: الترقيم، الإعدادات، التخزين، سجل النشاطات، التنبيهات، تصدير Excel
├── security/      إعدادات الأمان، المصادقة، سياسة كلمات المرور، قفل الحساب
├── service/       منطق الأعمال لكل مسار
├── web/           واجهات REST
├── job/           المهام المجدولة والتنبيهات التلقائية
├── dto/           كائنات نقل البيانات
└── config/        التهيئة والبيانات التجريبية

src/main/resources/
├── application.yml
├── db/migration/  سكربتات Flyway لـ SQL Server
└── static/        الواجهة الكاملة (HTML/CSS/JS)

sql/               سكربتات إنشاء القاعدة واستعلامات جاهزة للمكتب
data/              المرفقات والنسخ الاحتياطية وقاعدة التطوير (تُنشأ تلقائياً)
```

## ما جرى التحقق منه

مجموعة اختبارات شاملة في [QanoonEndToEndTest.java](src/test/java/com/qanoon/QanoonEndToEndTest.java) — **١٦ اختباراً تمر بالكامل** (`mvn test`):

- زرع البيانات التجريبية، تسجيل الدخول، رفض كلمة المرور الخاطئة، ورفض غير المسجّل بـ 401.
- لوحة المعلومات والقوائم المرجعية وكل شاشات القوائم الست.
- **بوابة التحويل**: التحويل ممنوع مع استئناف معلّق، وممنوع في اليوم الأخير من أجل الطعن، ومسموح عند نهائية الحكم — ومحاولة التحويل مرتين مرفوضة. والرفض يقع على **الخادم** لا على الواجهة فقط.
- **بوابة الاستيفاء**: الإغلاق مرفوض ما دام هناك متبقٍ.
- **قفل الرأي**: المدير نفسه لا يستطيع تعديل رأي موقّع، والتصحيح يُنشئ رأياً جديداً.
- **المراجعة المزدوجة**: كاتب الرأي لا يستطيع مراجعة رأيه.
- **التوزيع الذكي**: المرشحون مرتبون تنازلياً، والدرجة ضمن ١٠٠، وسبب الإسناد موثّق.
- **الصلاحيات**: المستشار لا يصل لشاشات الإعدادات ولا المستخدمين.
- **قفل الحساب** بعد المحاولات الفاشلة.

كما جرى تشغيل سكربتات SQL فعلياً على SQL Server 2022 Express: أُنشئت الجداول الـ ٢٦ والأدوار الخمسة و٦٦ صلاحية والإعدادات العشرة، وتم التأكد من أن النص العربي يُخزَّن ويُسترجع سليماً.

> ملاحظة: تعذّر تشغيل خادم الويب داخل بيئة الأدوات المستخدمة في البناء لأنها تحجب إنشاء قنوات NIO المحلية (`Selector.open()`)، وهو قيد بيئي لا علاقة له بالكود — ولذلك جرى التحقق من الواجهات عبر MockMvc الذي لا يحتاج منفذاً. عند تشغيلك للنظام من الطرفية العادية سيعمل الخادم طبيعياً.

## ملاحظات

- الواجهة بالكامل من اليمين لليسار، والقائمة الجانبية على اليمين، بتصميم **Microsoft Fluent UI 2** — أزرق مؤسسي/رمادي محايد.
- العملة: الدرهم الإماراتي (AED). التواريخ ميلادية بصيغة `dd/MM/yyyy`. المنطقة الزمنية `Asia/Dubai`.
- التنبيهات داخل النظام فقط، والإنذارات تُسجَّل يدوياً في سجل التواصل. لا يوجد ربط برسائل SMS أو بريد في هذه النسخة.
- التحقق الثنائي (2FA) مؤجّل لنسخة لاحقة بناءً على طلبك.
- لا يوجد أي اتصال بشبكة خارجية: لا خطوط ولا مكتبات من الإنترنت — النظام يعمل بالكامل داخل الشبكة المحلية.
